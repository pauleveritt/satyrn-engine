# V5 — a real whole-attempt turn and wall-clock budget

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans.

**Status: confirmed 2026-09-11.** The proposal (`docs/superpowers/research/2026-09-11-v5-budget-proposal.md`) is confirmed; this is its plan.

**Goal:** an engine-owned turn limit and wall-clock deadline over the whole attempt, retaining partial work on exhaustion.

**Architecture:** a new pure module `src/satyrn_engine/budget.py` holds the budget declaration and accounting; `delivery.py` enforces it while the implementer streams, terminating on exhaustion and retaining/validating the partial candidate. No change to the implementer command; no automatic repair.

**Spec:** the confirmed proposal above; `CLAUDE.md`'s rules.

## Confirmed decisions carried from the proposal

- `ExitCode.BUDGET_EXHAUSTED`; exhaustion is **produced-but-partial**, never a preflight refusal.
- A declared-but-unenforced budget is its own state — no ambiguous `None`.
- A phase-4 exhaustion is an **ordinary failed repair** (a counted observation), not an infrastructure stop.
- A passed validation on an exhausted attempt is **not** a completion.
- The composed route's own validation stop is a separate Backlog item in `satyrn-evals`; V5 does not silently depend on the grader.

## Global constraints

- Default tier: no model, no network, no subprocess; the planted spawn tripwire stays armed. Real processes live in the marked integration tier.
- A refusal test has a sibling success test.
- Modern 3.14 Python; cite file:line; a correction is recorded, not edited away.
- The budget counter is engine-owned: a turn is counted from the implementer's own stream, never from model prose.

## Task 2: `budget.py` — declaration and accounting

**Files:** `src/satyrn_engine/budget.py`, `tests/test_budget.py`

**Interfaces:**

```python
@dataclass(frozen=True, slots=True)
class Budget:
    turn_limit: int | None = None
    deadline_seconds: float | None = None
    @property
    def declared(self) -> bool: ...

class BudgetState(StrEnum):
    WITHIN = "within"
    TURN_EXHAUSTED = "turn_exhausted"
    DEADLINE_EXHAUSTED = "deadline_exhausted"
    NOT_DECLARED = "not_declared"

@dataclass(frozen=True, slots=True)
class BudgetUsage:
    state: BudgetState
    turns_used: int
    seconds_used: float

class TurnCounter:
    def feed(self, line: str) -> None: ...   # counts turn_start events
    @property
    def turns(self) -> int: ...
```
